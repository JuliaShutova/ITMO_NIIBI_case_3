# ITMO_NIIBI_case_3
Bioinformatics pipeline для поиска генетических причин редких наследственных заболеваний. Система выполняет фильтрацию и аннотацию генетических вариантов, сопоставляет их с фенотипическими признаками пациента и формирует ранжированный список кандидатных генов и вариантов с обоснованием приоритетности.
